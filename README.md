# Video Inventory HUB

Personal manager for Amazon Influencer and YouTube videos.

- **Upcoming** — plan videos with title, description, and tags (AI-generated or manual)
- **In Progress** — videos being worked on
- **Completed** — finished videos with their live published link

One-tap color-coded buttons move a card between sections. Search, platform filters,
live counts, and Export/Import backup included.

Hosted free via GitHub Pages: https://cyberjo50.github.io/video-inventory-hub/
